# SSTSS-GenSim-A-Modular-Tool-Chain-for-End-to-End-Safety-Evaluation-of-Automated-Driving-Systems

1. **Results_Scenario_Execution_Module** - Contains all Log files generated by the scenario execution module for each simulation run.</br>
   
2. **Results_Data_Collection_Module** - Contains all CSV files generated by the data collection module for each simulation run.</br>
  
3. **Results_Safety_Evaluation_Module** - Contains all CSV files generated by the safety evaluation module for each simulation run. </br>

4. **Euro-NCAP-SceanrioCatalog.pdf**  - List of scenarios provided by Euro-NCAP. </br>

5. **FollowLeadVehicle_data.csv** - shows the output generated by the Data Collection Module of the SSTSS-GenSim Tool. </br>

6. **FollowLeadVehicle_metrics.csv** -shows the output generated by the Safety Evaluation of the ADS Module of the SSTSS-GenSim Tool. </br>

7. **FollowLeadVehicle.json** --shows the output generated by the Scenario Execution Module of the SSTSS-GenSim Tool. </br>

8. **FollowLeadVehicle.py**  - shows the output generated by the Sceanrio Implementation Module of the SSTSS-GenSim Tool. </br> 

9. **FollowLeadVehicle.xml**  - shows the output generated by the Scenario Configuration Module of the SSTSS-GenSim Tool. </br>

10. **NHTSA-SceanrioCatalog.pdf**  - List of scenarios provided by the US National Highway Traffic Safety Administration. </br> 

11. **Plots** show the plots for safety metrics calculated for each set of input parameters generated by the Data Visualization and Report Module of the SSTSS-GenSim Tool. </br>

12. **Simulation-Report**  - shows a sample of a simulation report  generated by the Data Visualization and Report Module of the SSTSS-GenSim Tool </br>

13. **Singapore-ScenarioCatalog**  - List of scenarios provided by the  Land Transport Authority of Singapore. </br>

14. **Tool-Demo** - Provides a demo to use the  SSTSS-GenSim Tool </br>

15. **A sample output of the SSTSS Process** - shows an example output of the SSTSS Process.
